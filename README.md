# Toggle
Toggle is an app to measure the hapiness in the world.

## Quick start
Install the dependencies:
```
git clone https://github.com/HappyGlobe/toggle
cd src
npm install
```

## Run
```
npm run dev
```

**Note:** Toggle runs over the port 5000.

## Important
The postgres database it's running at a remote server, not locally. And it's is not 100% ready yet.
